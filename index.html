Les notions abordées

Chaque notion associe une idée à un exemple court. Les extraits utilisent des jeux de données fournis avec R, donc vous pouvez les copier et les lancer tels quels.

Importer et explorer

Charger un fichier, repérer les types de variables et les valeurs manquantes avant toute analyse.

library(tidyverse)
donnees <- read_csv("data/ventes.csv")
glimpse(donnees)
summary(donnees)

Transformer avec le tidyverse

Filtrer, regrouper et résumer un tableau avec le pipe natif |>.

mtcars |>
  filter(cyl == 4) |>
  group_by(gear) |>
  summarise(mpg_moyen = mean(mpg))

Visualiser avec ggplot2

Montrer la relation entre deux variables avant de la modéliser.

ggplot(mtcars, aes(wt, mpg)) +
  geom_point() +
  geom_smooth(method = "lm")

Statistiques et régression

Estimer un effet, lire les coefficients et juger la qualité de l’ajustement.

modele <- lm(mpg ~ wt + hp, data = mtcars)
summary(modele)
confint(modele)

Machine learning avec tidymodels

Séparer apprentissage et test, entraîner un modèle, puis mesurer sa performance sur des données jamais vues.

library(tidymodels)
split <- initial_split(iris, prop = 0.8, strata = Species)
rf <- rand_forest(trees = 500) |>
  set_engine("ranger") |>
  set_mode("classification")
fit(rf, Species ~ ., data = training(split))

Reproductibilité

Figer les versions des paquets et produire un rapport qui se régénère d’une seule commande.

renv::init()
renv::snapshot()
# dans le terminal
quarto render rapport.qmd

Un parcours conseillé

Si vous débutez en R, cet ordre évite de modéliser des données que l’on n’a pas encore comprises.

  1. Installer l’environnementR, puis Positron ou RStudio, et le paquet tidyverse.
  2. Explorer les donnéesDimensions, types, valeurs manquantes, distributions.
  3. Transformer et visualiserdplyr et ggplot2 pour poser les bonnes questions.
  4. ModéliserRégression, puis modèles de classification ou de prévision.
  5. Évaluer et communiquerValider sur des données de test, puis rédiger un rapport reproductible.
